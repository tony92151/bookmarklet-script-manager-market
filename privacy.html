隱私權政策

Last updated: September 26, 2026 / 最後更新：2026 年 9 月 26 日

摘要

Bookmarklet Script Manager 的內建指令碼管理功能會在您的裝置上運作。指令碼名稱與原始碼只會儲存在 chrome.storage.local。

Bookmarklet Script Manager's built-in script-management features operate on your device. Script names and source are stored only in chrome.storage.local.

擴充功能本身不會將指令碼、網頁內容、瀏覽資料或個人資訊傳送給開發者或其他第三方。

The extension itself does not send scripts, page content, browsing data, or personal information to the developer or other third parties.

資料儲存與傳輸

您儲存的指令碼名稱與原始碼會留在瀏覽器的本機擴充功能儲存空間。擴充功能不會將它們傳送到遠端服務，開發者也不會蒐集它們或與第三方分享。

Your saved script names and source code stay in your browser's local extension storage. They are not sent to a remote service by the extension, collected by the developer, or shared by the developer with third parties.

自訂指令碼會在網頁的 MAIN world 中執行。視其程式碼而定，它們可能讀取或修改網頁資料，也可能與外部服務通訊。此類通訊是由使用者所選的指令碼發起，而不是由 Bookmarklet Script Manager 或其開發者發起。請先檢視並確認您信任該指令碼，再加以執行。

Custom scripts run in the page's MAIN world. Depending on their code, they may read or modify page data and may communicate with external services. Any such communication is initiated by the user-selected script, not by Bookmarklet Script Manager or its developer. Review and trust a script before running it.

權限

storage
在瀏覽器本機儲存您儲存的指令碼名稱與原始碼。
Stores the script names and source you save locally in the browser.
activeTab
當您執行已儲存的指令碼或測試網頁時，暫時授權存取目前分頁。
Grants temporary access to the current tab when you run a saved script or test the page.
scripting
在您點選「Test this page」時測試目前網頁；若未開啟 Allow user scripts，也可透過備用方式在目前網頁執行已儲存的指令碼。網頁測試不會執行已儲存的指令碼，也不會將網頁資料傳送至其他地方。
Tests the current page when you click Test this page and runs saved scripts there through a fallback when Allow user scripts is off. The page test does not run saved scripts or send page data elsewhere.
userScripts
讓擴充功能在您選擇的網頁上執行您已儲存的自訂指令碼。
Lets the extension run the custom scripts you have saved on the page you choose.

支援

如有隱私權問題或需要支援，請在 GitHub Issues 提出問題。

For privacy questions or support, please open an issue in GitHub Issues.
