開始使用

安裝並使用 Market 書籤工具

先從 Chrome 線上應用程式商店安裝 Bookmarklet Script Manager，再從 Market 複製工具的 GitHub 連結，儲存到擴充功能。

前往 Chrome 線上應用程式商店 瀏覽 Market 工具

版本提醒：GitHub 匯入功能從擴充功能 1.2.1 版開始提供。Chrome 線上應用程式商店的更新仍在審查；進行匯入步驟前，請確認管理頁已有「GitHub」分頁。

01 安裝擴充功能 02 複製 GitHub 連結 03 匯入工具 04 在網頁執行
01

Chrome 線上應用程式商店

安裝擴充功能

開啟 Bookmarklet Script Manager 商店頁面，點選「加到 Chrome」並確認瀏覽器提示。安裝後，從工具列開啟擴充功能；若看不到圖示，可從 Chrome 的擴充功能選單尋找。

本教學的 GitHub 分頁需要 1.2.1 或更新版本。

02

Bookmarklet Market

複製工具的 GitHub 連結

在 Market 工具清單選擇工具，查看說明與適用網站，再按卡片上的「複製 GitHub 連結」。執行前可開啟該 GitHub 連結，檢視原始碼。

Market → 工具卡片 → 複製 GitHub 連結

請使用複製到的、以 .js 結尾的 GitHub 檔案連結；不要貼到「指令碼內容」欄位。

03

Script Manager

匯入 GitHub 工具

開啟擴充功能，點選「管理指令碼」。在「新增指令碼」區塊切換到「GitHub」分頁，把連結貼進「GitHub JavaScript 檔案網址」，再按「儲存」。工具會出現在「已儲存的指令碼」清單中。

管理指令碼 → 新增指令碼 → GitHub → 儲存

儲存時會下載一份本機副本；GitHub 檔案日後更新，不會自動更新已儲存的工具。

04

適用網站

在目前網頁執行

前往工具卡片標示的適用網站，開啟擴充功能，點選已儲存的工具名稱。每次點選都只會在目前分頁執行一次。

執行前請先檢視腳本。自訂腳本可以讀取或修改它執行所在的網頁內容。

遇到問題？

常見狀況

找不到 GitHub 分頁

請確認已安裝 1.2.1 或更新版本。商店更新仍在審查，商店目前提供的版本可能尚未包含此功能。

GitHub 連結無法儲存

請使用公開的 https://github.com/.../blob/.../*.js 檔案連結。儲存庫首頁、raw.githubusercontent.com 連結或私人檔案都無法匯入。也請檢查網路連線後重試。

已儲存的工具無法執行

先確認目前網頁是工具的適用網站。若網站封鎖擴充功能的備用執行方式，請開啟 chrome://extensions，找到 Bookmarklet Script Manager →「詳細資料」，啟用「允許使用者指令碼」。若擴充功能仍顯示未啟用，請重新載入擴充功能或重新啟動 Chrome。Chrome 內部頁面等受限制的網頁無法執行腳本。

執行前請先檢視腳本。
