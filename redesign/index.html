  1. 安裝擴充功能

    安裝 Bookmarklet Script Manager。GitHub 匯入需要 1.2.1 或更新版本。

    前往 Chrome 商店

  2. 選好你的腳本

    從上方工具集查看用途與原始碼，按下「複製 GitHub 連結」。

    回到工具集

  3. 匯入並儲存

    開啟擴充功能的「管理指令碼」，到「GitHub」分頁貼上連結，再儲存。

    查看匯入示範

  4. 讓它發揮作用

    前往腳本適用的網站，從擴充功能選擇腳本執行，結果就出現在頁面上。

    查看執行方式
