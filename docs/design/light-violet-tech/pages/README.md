## 設計檢查限制

Taste 的靜態全庫掃描包含舊 CSS、腳本注入 UI 及教學模擬畫面，並未全綠；不可視為本輪所有規則通過。實際 Skill 頁檢查後已移除裝飾眉標、數字和分隔線，縮短中文主標。保留可讀的文件尺度與靜態教學內容，不為一般行銷頁的影片／照片／大型主視覺指標插入無關素材。紫色與工具卡片為使用者明確選擇；等寬字體僅用於程式碼及網址。Stack 字型以本地檔案載入，共用 CSS 中的 family 別名為 Market Text。
