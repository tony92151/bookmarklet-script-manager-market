Before you start

Do I need to publish to the Market?

No. You can use the Skill to make a personal bookmarklet. Catalog files and repository tests are only needed when integrating a tool into this repository.

Will it work on every page?

No. Bookmarklets run in the current webpage and may be limited by its security policy or cross-origin restrictions. They cannot run on browser-internal pages such as chrome://, and page changes can break a script.

What does the Skill provide?

It guides the assistant on page evidence, repeatable execution, feedback, and choosing a suitable interface. Generated code still needs to be reviewed and tested on the actual page.
